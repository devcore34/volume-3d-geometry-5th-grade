# Объём пространственных фигур в единичных кубах · 5 класс (3D-доска)

Интерактивный 3D-учебник для электронных досок и смартфонов по теме 5 класса **«Объём пространственных фигур в единичных кубах»** (стр. 111–114).

## Возможности
- **2D из учебника → 3D-модель:** каждая фигура сначала открывается как крупный плоский чертёж из учебника, а по кнопке **«Показать в 3D»** (`Пробел`) оживает в объёмную 3D-фигуру с вращением на 360°.
- **Скрытые ответы для класса:** все ответы скрыты по умолчанию и открываются только по нажатию кнопки **«👁 Ответ»** (`Enter`).
- **3D-резервуар («Что такое объём?»):** прозрачная ёмкость (`2×2×2`, `3×2×2`, `4×3×2`), которая плавно наполняется единичными кубами до краёв слой за слоем.
- **Инструменты исследования:** разнесение кубов (`0–100%`), срезы по слоям, пошаговый подсчёт, тык-счёт, снятие кубов, рентген, 3D-конструктор с проверкой 24 поворотов, маркер поверх доски и режим чистой доски (`Z`).
- **Оптимизация:** плавная работа на 4K-электронных досках и полная адаптация под телефоны.
- **Офлайн-версия:** файл `Открыть_3D_урок.html` можно запускать двойным кликом без интернета.

## Локальный запуск
```bash
npm install
npm run dev
```

## Сборка автономного файла
```bash
npm run build
```
